## Вихідна потреба

### Хто
Гравці, Game Masters, Бармени

### Що (проблема)
Поточний patrol квест:
1. Вимагає `required_time_minutes` — непотрібний таймер перебування в чекпоінтах
2. Дозволяє відвідувати чекпоінти в довільному порядку — не відповідає концепції "патруль"
3. При auto-complete НЕ нараховується нагорода (баг)

### Рішення
- Прибрати time-based механіку
- Чекпоінти відвідуються строго послідовно
- Радіус чекпоінта — 30м
- Auto-complete з нарахуванням нагороди (гроші + репутація + предмети)
- Попап завершення квесту на фронтенді

### Прес-реліз
> Патрульні квести тепер працюють як справжній патруль! Гравець отримує маршрут з точками, які потрібно відвідати строго по порядку. Підійшов до точки в радіусі 30м — вона зараховується, і відкривається наступна. Відвідав усі — квест автоматично завершується, нагорода нараховується миттєво.

### Критерії успіху
- [x] Чекпоінти відвідуються тільки послідовно
- [x] Прибрано required_time_minutes / accumulated_time_seconds
- [x] Auto-complete при відвідуванні всіх чекпоінтів
- [x] При auto-complete нараховується: гроші + репутація + предмети + stats
- [x] Location response повертає quest progress
- [x] Фронтенд показує попап завершення з нагородою
- [x] Маркери чекпоінтів на карті (активний/відвіданий/майбутній)
