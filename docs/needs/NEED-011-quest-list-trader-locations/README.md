# NEED-011: Quest List — Trader Locations & Accept Flow

**Статус:** spec
**Пріоритет:** P1

## Проблема

Гравець може прийняти квест прямо зі списку Available в PDA, минаючи трейдерів/бартендерів. Це ламає ігрову логіку — квести мають видаватися через NPC. Також немає інформації де знаходяться трейдери які видають квести.

## Прес-реліз

Тепер список доступних квестів у PDA показує де саме можна отримати завдання. Кожен квест вказує трейдера який його видає, а на карті відмічені їхні локації. Гравець бачить квест, бачить хто його дає і куди треба йти — і вирушає до потрібного NPC. Прийняти квест можна тільки на місці, через сторінку трейдера.

## Рішення

1. Прибрати кнопку ACCEPT з табу Available
2. Показувати тільки квести від трейдерів (NPC) та бартендерів
3. Показувати ім'я та тип issuer'а в картці квесту
4. Додати кнопку "Show on Map" — центрує карту на трейдері
5. Backend повертає координати issuer'а в response
