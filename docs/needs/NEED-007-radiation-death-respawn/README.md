## Що реалізовано

### Радіація
- Формула: `baseRate = radiationLevel5m / 300.0` (points/sec)
- Effective rate: `baseRate * (1 - resistPct/100.0)`
- Розрахунок часу в зоні через лінійну інтерполяцію P0→P1
- Правило "першої зони" (no stacking)
- Resist cap: 80%

### Смерть
- При radiation >= 100 → status=DEAD, lives-1, radiation=0
- Втрата предметів: 1-10% (equipment + backpack)
- Атомарна транзакція

### Респаун
- Зелені зони на карті (видимі всім)
- Прогрес накопичується поки гравець в зоні
- При 100% — кнопка "RESPAWN" (ручне натискання)
- Прогрес зберігається при виході з зони

### Обмеження мертвих
- ✅ Карта (навігація до респауну)
- ✅ Інвентар + екіпірування
- ✅ Торгівля з барменом (купівля)
- ❌ Підбір артефактів
- ❌ Торгівля з іншими
- ❌ Квести

### UI
- Header: ❤️ lives + ☢️ radiation (green/yellow/red)
- Жовтий банер в зоні радіації
- Повноекранний банер смерті
- Прогрес-бар респауну

### Backend
- `src/utils/radiation.py` — розрахунок радіації
- `src/handlers/location.py` — trigger_death(), respawn logic
- `src/handlers/players.py` — death, loot
- `POST /api/player/respawn` — відродження
