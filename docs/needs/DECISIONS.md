# Архітектурні рішення (ADR) STALKER PDA

## ADR-001: Serverless архітектура на AWS Lambda
**Дата:** 2026-01-02
**Статус:** Прийнято

**Контекст:**
Потрібна масштабована платформа з мінімальними операційними витратами.

**Рішення:**
AWS Lambda + API Gateway для всього бекенду. Кожен handler — окрема Lambda функція.

**Наслідки:**
- ✅ Мінімальні витрати (~$44/міс)
- ✅ Автоматичне масштабування
- ❌ Cold start затримки
- ❌ Обмеження Lambda (15 хв, 10 GB RAM)

## ADR-002: MySQL (RDS) як основна БД
**Дата:** 2026-01-02
**Статус:** Прийнято

**Контекст:**
Потрібна реляційна БД для ігрових даних з транзакціями.

**Рішення:**
AWS RDS MySQL 8.0 (db.t3.micro).

**Наслідки:**
- ✅ Надійні транзакції для торгівлі та інвентарю
- ✅ Managed сервіс
- ❌ Фіксована вартість навіть без навантаження

## ADR-003: DynamoDB для WebSocket з'єднань
**Дата:** 2026-01-02
**Статус:** Прийнято

**Контекст:**
Потрібно зберігати активні WebSocket з'єднання для real-time оновлень.

**Рішення:**
DynamoDB таблиця `pda-zone-connections-dev` з TTL.

**Наслідки:**
- ✅ Швидкий доступ
- ✅ Автоматичне видалення по TTL
- ✅ Serverless — оплата за запити

## ADR-004: JWT в cookies (не localStorage)
**Дата:** 2026-01-06
**Статус:** Прийнято

**Контекст:**
Потрібно зберігати токен авторизації на клієнті.

**Рішення:**
JWT зберігається в cookies (`pda_token`) з 7-денним терміном.

**Наслідки:**
- ✅ Автоматична відправка з кожним запитом
- ✅ Працює з Google Translate widget
- ❌ Потрібна CORS конфігурація

---

## ADR-005: SAM для Infrastructure as Code
**Дата:** 2026-01-02
**Статус:** Прийнято

**Контекст:**
Потрібен IaC інструмент для деплою Lambda + API Gateway.

**Рішення:**
AWS SAM з `sam sync --watch` для швидкої розробки.

**Наслідки:**
- ✅ Автодеплой за 10-20 сек
- ✅ CloudFormation під капотом
- ❌ Повільний повний деплой (3-5 хв)
