# Документація STALKER PDA — Needs System

## Структура

```
docs/needs/
  INDEX.md                  # Реєстр всіх потреб
  WORKFLOW.md               # Інструкція для AI (8 етапів)
  GLOSSARY.md               # Терміни проекту
  DECISIONS.md              # Архітектурні рішення (ADR)
  README.md                 # Цей файл — опис структури
  templates/                # Шаблони документів
  NEED-XXX-назва/           # Папка потреби
    README.md               # Опис + прес-реліз + рішення
    spec.md                 # Специфікація (10 розділів)
    api.md                  # API контракти
    ui.md                   # UI/UX дизайн
    errors.md               # Обробка помилок
    tasks.md                # Задачі
    tests.md                # Тест-кейси
    changelog.md            # Історія змін
```

## Як створити нову потребу

1. Визнач наступний номер в `docs/needs/INDEX.md`
2. Створи папку `docs/needs/NEED-XXX-назва/`
3. Скопіюй шаблони з `docs/needs/templates/`
4. Додай запис в `docs/needs/INDEX.md`

## Процес роботи (8 етапів)

1. **Draft** — створюємо потребу, описуємо проблему, пишемо прес-реліз
2. **Analysis** — задаємо питання по одному, фіксуємо відповіді
3. **Spec** — пишемо специфікацію, Acceptance Criteria
4. **Docs** — створюємо всі документи потреби
5. **Pre-check** — перевіряємо готовність до коду
6. **Implementation** — пишемо код (Backend First)
7. **Commit** — коміт після апруву
8. **Done** — оновлюємо статуси, changelog

## Правила

- Ніяких змін коду без апруву
- Перед зміною описати: навіщо, що, де, ризики
- Після кожної задачі оновлювати документацію
- Коміти з тегом: `[NEED-XXX] опис`
